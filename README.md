# Bastion Protocol — website

Static, bilingual marketing and support site for Bastion Protocol on Apple Vision Pro.

- English: `index.html`, `support.html`, `privacy.html`, `thanks.html`
- French: `fr/`
- Game screenshots: `AppStore/screenshots/`
- Browser preview: `Preview/` (an earlier version than the Vision Pro app)

Published with GitHub Pages from the root of `main`. The support form uses Web3Forms and the same destination as the Lexilo support site.
